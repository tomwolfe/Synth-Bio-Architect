# Synth Bio Architect

![Synth Bio Architect Screenshot](screenshots/Screenshot-1-30-2026.png)

An AI-powered tool for synthetic biology architecture and design, leveraging Google's Gemini API to generate research hypotheses, experimental designs, and grant proposals.

## Overview

Synth Bio Architect is a web application designed to accelerate the research process in synthetic biology. By integrating with Google's powerful `gemini-3-flash-preview` AI model, it helps researchers and bioengineers generate novel hypotheses, design detailed CRISPR/peptide experiments, and draft NIH-style grant proposals based on a simple research prompt.

The application provides a structured, three-phase output:
1.  **Phase 1: Hypotheses** - Generates three novel, grounded research directions, complete with supporting PubMed IDs (PMIDs).
2.  **Phase 2: Experimental Design** - Details a complete protocol and lists required reagents (Bill of Materials).
3.  **Phase 3: Grant Proposal** - Creates a draft proposal with a predicted impact score (0-100).

## Key Features

*   **AI-Powered Research Generation:** Utilizes the cutting-edge `gemini-3-flash-preview` model to create high-quality, domain-specific content tailored for synthetic biology.
*   **Structured, Actionable Output:** Parses AI responses into clear, organized sections (Hypotheses, Experimental Design, Grant Proposal) for easy reading and copy-pasting into lab notebooks or grant applications.
*   **Real-time Streaming:** Content is displayed as it's generated by the AI, providing immediate feedback and a more engaging experience.
*   **Integrated Bioinformatics Calculations:** A built-in Calculation Hub allows for deterministic analysis of DNA sequences (e.g., melting temperature, GC content, codon optimization) using a secure, sandboxed Python/`Biopython` backend.
*   **Literature Verification:** Automatically extracts and verifies PubMed IDs (PMIDs) mentioned in the AI-generated hypotheses using the NCBI E-Utilities API, ensuring scientific rigor.
*   **Simple API Key Management:** Securely store and manage your Google API key within your browser.
*   **Markdown Rendering:** Outputs are rendered as clean, well-formatted Markdown for optimal readability.
*   **One-Click Copying:** Copy any section of the generated output to your clipboard with a single click.
*   **Export to Benchling:** (Phase 2 only) Export your experimental design details as a JSON file for easy import into Benchling LIMS.
*   **Responsive Design:** Built with Tailwind CSS for a modern, clean interface that works seamlessly on desktop and tablet devices.
*   **Comprehensive Testing:** Includes a robust test suite for the core response parser and API endpoints.

## Technologies Used

*   **Frontend Framework:** Next.js 16 (App Router)
*   **UI Framework:** Tailwind CSS v4
*   **State Management:** React Hooks (useState, useEffect)
*   **AI Integration:** Google Generative AI SDK (`@google/genai`)
*   **Markdown Rendering:** `react-markdown` with `remark-gfm`
*   **Testing:** Vitest with jsdom
*   **Styling:** PostCSS with Autoprefixer
*   **Build Tool:** Vite (for testing)
*   **Deterministic Bioinformatics:** Python 3, `Biopython` (via secure API endpoint)
*   **NCBI Integration:** E-Utilities API for PubMed ID verification

## Getting Started

### Prerequisites

*   Node.js (v20.9.0 or higher)
*   npm or yarn

### Installation

1.  Clone the repository:
    ```bash
    git clone https://github.com/your-username/synth-bio-architect.git
    cd synth-bio-architect
    ```

2.  Install the dependencies:
    ```bash
    npm install
    ```

### Configuration

1.  **Obtain a Google API Key:**
    *   Go to the [Google Cloud Console](https://console.cloud.google.com/).
    *   Create a new project or select an existing one.
    *   Enable the **Generative Language API**.
    *   Navigate to **APIs & Services > Credentials**.
    *   Create a new API Key. **Important:** For security, set appropriate API key restrictions (e.g., HTTP referrers) and configure billing and quotas.

2.  **Set the API Key:**
    *   Start the development server (see below).
    *   In the **sidebar**, paste your Google API key into the input field.
    *   Click the **Save Key** button. The key will be stored in your browser's `localStorage`.

### Running the Application

Start the development server:
```bash
npm run dev
```

Open your browser and navigate to `http://localhost:3000`.

### Running Tests

To run the test suite:
```bash
npm run test
```

## Usage

1.  **Enter your API Key:** Paste your Google API key into the sidebar and click "Save Key".
2.  **Describe Your Research:** In the main panel, enter a detailed description of your research challenge (e.g., "Find me a way to cure ALS using CRISPR and AI-designed peptides").
3.  **Generate:** Click the **Generate Research Plan** button.
4.  **Review & Copy:** As the AI generates the response, each section (Hypotheses, Experimental Design, Grant Proposal) will appear in real-time. Use the "Copy" button next to each section to copy the content to your clipboard.
5.  **Verify Literature:** PMIDs found in the Hypotheses section are automatically verified. A verification panel will show which IDs are valid.
6.  **Use the Calculation Hub:** Use the dedicated section to analyze DNA sequences for melting temperature or perform a simple codon optimization.
7.  **Export:** For Phase 2 (Experimental Design), click "Export to Benchling" to download a JSON file.

## Security Note

The Google API key is stored in the browser's `localStorage`. While this is convenient for the user, it means the key is accessible via the browser's developer tools. **This is not a secure method for storing sensitive credentials in a production environment.**

*   **For Development/Personal Use:** This approach is acceptable for local testing and personal projects.
*   **For Production Deployment:** A backend server **must** be implemented. This server would handle API key management securely (e.g., using environment variables) and proxy all requests to the Gemini API, ensuring your key is never exposed to the client's browser.

The deterministic bioinformatics calculations (melting temperature, codon optimization) are performed via a secure API endpoint (`/api/bio`) that runs a Python script (`bio_worker.py`) in a sandboxed environment. This prevents any potential client-side code injection and ensures the integrity of the calculations.
